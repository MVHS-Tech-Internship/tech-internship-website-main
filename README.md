# MVHS Tech Internship Website

A Flask-based website for the MVHS Tech Internship program, showcasing the organization's mission, accomplishments, and resources. The site promotes peer-driven technology support, educational initiatives, and AI-powered applications.

## Features

- **Home**: Welcome page with mission overview and upcoming events
- **About Us**: Program information, accomplishments, and team details
- **News & Media**: Latest updates and announcements
- **Resources**: Educational materials and tools
- **Contact Us**: Contact form and information
- **Support Us**: Ways to support the program

## Tech Stack

- **Backend**: Flask (Python)
- **Templates**: Jinja2
- **Styling**: Custom CSS with responsive design
- **Icons**: Font Awesome

## Setup

1. Install Python 3.x
2. Install Flask:
   ```bash
   pip install flask
   ```
3. Run the application:
   ```bash
   python main.py
   ```
4. Open your browser and navigate to `http://localhost:8000`
